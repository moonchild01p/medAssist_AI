# MedAssist AI

MedAssist AI is an intelligent medical SaaS platform designed to assist healthcare professionals in patient management, medical diagnosis assistance, and early risk prediction using Artificial Intelligence.

## Features (MVP)
- Secure authentication for healthcare professionals
- Patient management and electronic medical records
- NLP-based medical consultation summarization
- Secure and anonymized health data processing
- Role-based access control

## Technologies
- Frontend: Flutter (Web)
- Backend: FastAPI
- Database: PostgreSQL
- AI / ML: TensorFlow, PyTorch
- NLP: Hugging Face Transformers
- Security: JWT, HTTPS, Bcrypt
- Deployment: Docker
